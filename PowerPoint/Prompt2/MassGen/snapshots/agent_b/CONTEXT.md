# Task Context

Evaluating and improving a PowerPoint presentation about Quantum Computing for high school students. The presentation must use a "maze" metaphor throughout.

## Key Requirements
- 10 slides
- Continuous maze metaphor
- Progressive complexity (Superposition/Entanglement by slide 6)
- NO bullet points
- Dynamic layouts (side-by-side, top-heavy)
- Hyperlinked Quiz buttons on slides 4 and 8

## Visual Style
- Scientific but engaging for high schoolers
- Maze visuals (corridors, walls, paths)
- Standout gold/bright Quiz buttons
