# Task Context

Building a 10-slide PowerPoint (.pptx) presentation explaining Quantum Computing to high school students.

## Key Requirements
- Continuous "maze" metaphor throughout all slides
- Progressive complexity: basic concepts → superposition & entanglement by slide 6
- No bullet points — dynamic layouts (side-by-side boxes, top-heavy titles, etc.)
- Hyperlinked interactive "Quiz" button on slides 4 and 8 that visually stands out
- Must be a downloadable .pptx file

## Visual Style
- Dark theme with neon/bright accents
- Maze-inspired visual decorations
- Gold/bright quiz buttons that pop against dark backgrounds
