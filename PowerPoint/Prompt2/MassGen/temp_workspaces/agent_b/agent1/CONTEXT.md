# Task Context

Building a 10-slide .pptx presentation explaining Quantum Computing to high school students.
Uses a "maze" as a continuous visual metaphor throughout all slides.

## Key Requirements
- 10 slides, progressive complexity (basic → superposition → entanglement)
- NO bullet points anywhere — use dynamic layouts (side-by-side text boxes, top-heavy titles)
- Maze metaphor: classical computing = one path at a time, quantum = exploring all paths simultaneously
- Hyperlinked interactive "Quiz" button on slides 4 and 8 that visually stands out
- Target audience: high school students (accessible language, engaging visuals)

## Visual Style
- Deep blue/indigo primary (maze/quantum theme)
- Maze-inspired geometric shapes and patterns
- Clean, modern, educational aesthetic
