# Task Context

Creating a 10-slide Quantum Computing presentation for high school students using a continuous "maze" metaphor.

## Visual Style
- Dark, modern theme (MAZE_DARK background).
- Neon accents (MAZE_ACCENT) representing maze walls.
- Dynamic layouts with text boxes, no bullet points.
- Gold "Quiz" buttons for interactivity.

## Key Constraints
- 10 slides exactly.
- Maze metaphor throughout.
- Progression: Basic -> Superposition/Entanglement by Slide 6.
- No bullet points.
- Interactive quiz buttons on slides 4 and 8.
