# Task Context

Generating a 10-slide PowerPoint presentation about Quantum Computing for high school students.

## Visual Metaphor
- Continuous 'Maze' metaphor throughout.
- Isometric 3D maze paths, glowing neon cyan lines, dark navy backgrounds.
- Minimalist, futuristic, high-tech aesthetic.

## Key Requirements
- No bullet points.
- Side-by-side text boxes and top-heavy layouts.
- Interactive Quiz buttons on slides 4 and 8.
- Progression from basic (bits) to complex (entanglement) by slide 6.
