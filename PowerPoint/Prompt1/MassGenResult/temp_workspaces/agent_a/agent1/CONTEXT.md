# Task Context

Building a Python script that generates a professional 8-slide Quarterly Earnings PowerPoint deck
for a SaaS company using the python-pptx library. The deck is named Q4_Earnings.pptx.

## Key Details
- Revenue data: Q1=$2.4M, Q2=$2.8M, Q3=$3.1M, Q4=$2.9M
- Customer churn increased 4% in Q4
- Native bar chart on Slide 3 (quarterly revenue comparison)
- Native pie chart on Slide 5 (churn breakdown)
- "Key Takeaway" text box on every slide
- CFO speaker notes addressing Q4 revenue dip on every slide
- Robust error handling throughout
